System Architecture
1. User Interface (Browser) HTML5 / CSS3 / JS / Bootstrap
2. Flask App Server Routes, Auth, Blueprints, Sessions
3. Detection Engine OpenCV + YOLOv8 + CNN Classifier
4. Database & Speech Layer SQLite & Web Speech API TTS

Data flows bidirectionally: input frames/streams move downstream through OpenCV preprocessing to YOLOv8 inference, and results with safety rules return to the client browser for audio alert playback.

Step-by-Step Methodology
  • 1
    Image/Video Upload or Live Feed Capture
    User selects an image, driving video, or enables continuous webcam mode.
  • 2
    OpenCV Color & Geometry Preprocessing
    HSV color channel separation, noise suppression, and contour segmentation.
  • 3
    Sign Localization & HUD Annotation
    Bounding box coordinates extracted and styled with cybernetic HUD brackets.
  • 4
    Deep Classification & Spoken Voice Alert
    Identifies 10 standard sign classes, computes certainty %, and triggers TTS voice alert.
  • 5
    Database Archival & PDF Audit Export
    Stores timestamped log in SQLite and provides downloadable diagnostic PDF report.

9 Core Project Modules

1. Auth Module
Session authentication, Werkzeug password hashing, and role-based permissions.
2. Image Detection
Single photo upload & 1-click test sample gallery with HUD overlays.
3. Video Detection
Extracts and processes sampled keyframes across uploaded driving video footage.
4. Live Webcam HUD
Real-time driver assistant mode with autonomous 2-second scanning loop.
5. Spoken Voice Alerts
Web Speech API synthesizes driving safety advisories for zero-distraction driver aid.
6. Analytics Dashboard
Live statistical metric cards and Chart.js sign category breakdown charts.
7. Detection History
Searchable and filterable database audit log with confidence visualizers.
8. PDF Reports
Generates downloadable formal inspection reports with PSN Engineering College banner.
9. Admin Panel
Comprehensive user administration, privilege toggles, and server diagnostics.
